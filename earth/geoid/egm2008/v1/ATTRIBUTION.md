# NGA EGM2008 5-minute geoid grid

Producer: NGA; GeographicLib PGM distribution.
Source: https://geographiclib.sourceforge.io/C++/doc/geoid.html.
License: [other](https://raw.githubusercontent.com/OSGeo/PROJ-data/master/us_nga/us_nga_README.txt).

Changes: Original ZIP retained and PGM extracted unchanged. Full native grid converted without decimation; raw uint16 values and scaled float64 meter heights both retained. ZSTD level 6.
